# User experience

- Created: 25 October 2026
- Last updated: 25 October 2026
- Status: Maintained rule for agents
- Related framing: [Project instructions](../../AGENTS.md)

The player uses the keyboard.

- Every action of the player has a key. The player never needs the mouse to play the game.
- A button on the page only does the same action as a key, for example the sound button does the same action as the key M.
- When you add an action, add its key, and write the key in the section "Keys" of the file [README.md](../../README.md) and in the file [src/view/CONTEXT.md](../../packages/git_runner/src/view/CONTEXT.md).
