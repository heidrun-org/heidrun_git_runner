# Directory Context: `/data`

## Purpose
The data files of the repository that no package builds: the branding images of Heidrun Code.

## Key Exports & Entry Points
- `images/`: the branding images. See [docs/branding.md](../docs/branding.md).

## Rules
- The images are copies of the folder `data/images` of the repository heidrun. Change them there first, then copy them here.
- No package imports a file of this folder: the game draws every picture with code.

## Background
- The branding and its colors are in [docs/branding.md](../docs/branding.md).
